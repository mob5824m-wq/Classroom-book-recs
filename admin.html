Open Library (openlibrary.org) grabs books to match each student's genres and themes, and shows a “🔄 New ideas” button so they can ask for a different set. It needs internet on the computer running this server; if it can't be reached, the built-in list is shown automatically instead, so students are never left with an empty list.
